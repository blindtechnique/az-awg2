# разбор, а не отписка: почему именно здесь код возврата никуда не попадает.
#
# Формат:  файл :: правило :: код :: обоснование
#
# Если код изменится, строка перестанет к чему-либо относиться, и аудит
# сообщит об этом отдельно — чтобы список не гнил.

# Привязка stdin к терминалу при установке через bash <(curl…): там stdin занят
# потоком скрипта, и read берёт данные оттуда, а не с клавиатуры. Вечность
# перенаправления здесь ЗАМЫСЕЛ — оно нужно на весь диалог. Гибель оболочки
# исключена проверкой [ -r /dev/tty ] прямо перед exec.
install.sh :: exec-unbraced :: exec < /dev/tty :: ограждено [ -r /dev/tty ] выше по условию; вечное перенаправление stdin здесь и есть цель
install.sh :: exec-unbraced :: [ -r /dev/tty ] && exec < /dev/tty :: проверка стоит в той же строке; перенаправление нужно на весь диалог удаления
